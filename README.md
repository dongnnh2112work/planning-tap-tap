# Planning Tap Tap

Nơi các agent trong team cập nhật tiến độ dự án Tap Tap. Bee (PM) đọc repo này mỗi ngày để theo dõi và báo anh BeeNgyy.

## Cách cập nhật
- Mỗi agent có 1 file trong `progress/` (vd `progress/TECH-LEAD.md`). Chỉ sửa file của mình.
- Thêm mục mới ở **trên cùng**, theo mẫu:

```
## YYYY-MM-DD
- Đã xong: ...
- Đang làm: ...
- Kế tiếp: ...
- Vướng / rủi ro: ... (ghi "không" nếu không có)
- Cần anh BeeNgyy quyết: ... (ghi "không" nếu không có)
```

- Commit message: `[TÊN-AGENT] YYYY-MM-DD cập nhật tiến độ`.
- Không đưa mật khẩu, API key, dữ liệu khách hàng thật vào repo.
- Không ghi số liệu đoán; chỗ chưa chắc ghi "chưa xác minh".

## Tài liệu
- [RULES.md](RULES.md): **rule làm việc, bắt buộc đọc** (vai trò, sửa file, báo trước, họp thứ 3).
- [CONTEXT.md](CONTEXT.md): **đọc đầu tiên**. Tap Tap là gì, hai hướng, đã có / còn thiếu, câu hỏi đang mở.
- [TIMELINE.md](TIMELINE.md): Gantt tới 31/12. **W1/12 (30/11–6/12) internal launch, W2/12 (7–13/12) release.**
- [FLOW_B2B.md](FLOW_B2B.md): flow MVP B2B, màn hình, phạm vi, KPI pilot.
- [DECISIONS.md](DECISIONS.md): các quyết định đã chốt và đang chờ.
- [meetings/](meetings/): biên bản họp thứ 3 hằng tuần (mẫu: `meetings/TEMPLATE.md`).
- [archive/](archive/): bản cũ để khôi phục.

Chiến lược đang chờ anh BeeNgyy chốt; xem `DECISIONS.md`.
