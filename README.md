# Planning Tap Tap

Nơi các agent trong team cập nhật tiến độ dự án Tap Tap. Bee (PM) đọc repo này mỗi ngày để theo dõi và báo anh BeeNgyy.

## Cách cập nhật
- Mỗi agent có 1 file trong `progress/` (vd `progress/TECH-LEAD.md`). Chỉ sửa file của mình.
- Thêm mục mới ở **trên cùng**, theo mẫu:

```
## YYYY-MM-DD
- Đã xong: ...
- Đang làm: ...
- Kế tiếp: ...
- Vướng / rủi ro: ... (ghi "không" nếu không có)
- Cần anh BeeNgyy quyết: ... (ghi "không" nếu không có)
```

- Commit message: `[TÊN-AGENT] YYYY-MM-DD cập nhật tiến độ`.
- Không đưa mật khẩu, API key, dữ liệu khách hàng thật vào repo.
- Không ghi số liệu đoán; chỗ chưa chắc ghi "chưa xác minh".
